# particle-swarm (vanilla JS + canvas, no deps)
**Use when:** a page needs a cursor swarm that magnetises to buttons and headings. Hover effect, landing hero, reel b-roll (screen-record it).
**Shows:** a hive. The particles form an ordered golden-angle disc that turns slowly around the cursor. One particle in 12 is a scout: each scout keeps one element and shuttles to it and back, if that element is on screen and within 600px. Near a `[data-swarm]` element, part of the swarm leaves the hive and travels along the element outline at a constant speed. The closer the cursor, the larger that share (about 0% at 90px away, 100% over the element). The rest stay in the hive. The page adds no CSS highlight: the particles are the moving border.
- `data-swarm="border"`: the particles run along the border (rounded corners too), tight to it with a small random offset. Set `border-color: transparent` on the element. The element leans toward the cursor (`data-swarm-magnet`).
- `data-swarm="text"`: the particles run along the glyph outlines (contours, not fill) of the text (one line of text only).
- `data-swarm="shape"` with `data-swarm-shape="egg"`: the particles draw an Easter egg centred on the element (the element can be an invisible button). The egg is 2.5x the element height and may extend beyond it. Each click cycles the design: 0 plain outline, 1 horizontal stripes, 2 dots, 3 zigzag band, 4 waves. `data-swarm-design="n"` picks the start. The shapes are point lists with normals, walked by the same code as the text outlines. An open line is walked there and back.
- `data-swarm-scout="off"`: scouts skip this element. Use it on a target that must stay hidden.
- Invisible logo trick: a short wordmark with `color: transparent`, `text-shadow: none` and `data-swarm="text"` (demo: "DNP"). Nobody sees it until the swarm traces its outline. Keep the glow CSS off it and add `data-swarm-scout="off"` so scouts do not reveal its box.
- The swarm takes the tint of the element (`--swarm-color`) and gets brighter while it holds an element.
- Halos are small and uneven; some particles have none.
- Modes: `glow` (additive light) or `contrast` (canvas `mix-blend-mode: difference`, it inverts every pixel it crosses).
**Run:** open `src/index.html` in a browser. No build, no server.
**Use it:** `<script src="swarm.js"></script>` then `const s = createSwarm({ count: 700, color: '#7cf7ff', mode: 'glow', field: 90 })`. API: `s.set(partial)`, `s.get()` (a copy of the options), `s.setMode('contrast')`, `s.setCount(n)`, `s.setPath(style)`, `s.setColor(c)`, `s.refresh()` (after DOM changes), `s.destroy()`.
**Live tuning:** `s.set({ ... })` changes options at run time; the frame loop reads them each frame. Options (default): `count` (700), `spacing` (24, hive radius px), `size` (1, particle size scale), `orbit` (1, hive orbit speed, 0 = still), `stiffness` (1, follow tightness), `scouts` (1/12, scout share, 0 = none), `field` (90, pull radius px), `pathSpeed` (90, px/s along an outline), `curve` (2, share of the swarm on the element = k^curve), `glow` (1, alpha scale), plus `mode`, `color`, `textPath`, `magnet`, `trail`. The demo has a Tune panel (button in the control bar) with one slider per option.
**Style hook:** the script writes `--swarm` (0..1) and the class `.is-swarmed` on each element. Optional: the demo does not use them. Use them in your own CSS if you want a highlight on top of the swarm.
**Button padding:** set it in em, so it scales with the font. Text button: `0.55em 1.1em` (x = 2 × y, height 2.1em). A pill needs x ≥ half the height, so the text stays clear of the curve. The label grows up to 19% (swarm and click burst), so keep x ≥ 10% of the label width. Size a button type with `font-size` only. Change `--pad-y` / `--pad-x` when a type needs a change; never use px padding. Icon button: a square at the text-button height. Text link: `0.25em`. Shape buttons (player, egg) keep a fixed size, because the swarm draws their ring.
**Rules:** canvas is `position: fixed` with `pointer-events: none`. With `prefers-reduced-motion`, the swarm is calm: 30% of the particles, no idle drift, no element lean. Set `reducedMotion: 'off'` to remove it. The element lean uses the CSS `translate` property, so it does not fight a `transform`.
